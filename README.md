## 🎨 Design Philosophy: Media-Reactive Comic Poster Engine

- ❌ **No Flat Cartoon Mascots:** Zero cartoon characters or generic vector animations competing with real client products.
- ✅ **Real Media as the Hero:** Real client photography and videos (Properties, Food & Honey, Sports gear, Fashion, Local cafes) take center stage.
- ✅ **Auto-Extracted Swatches (WASM):** 5 swatches (`vibrant`, `dark`, `light`, `muted`, `darkMuted`) dynamically extracted and mapped to OKLCH CSS custom properties.
- ✅ **Guaranteed WCAG AA Contrast:** Real-time contrast validation ensuring auto-colored typography maintains a compliant $\ge 4.5:1$ readability ratio.
- ✅ **High-Energy Comic Poster Typography:** Bold angled frames, 3D retro drop-shadow extrusions, speedlines, and starburst stickers.

## 🛠 Tech Stack (2026 Modern Architecture)

- **Frontend Framework:** Next.js 16.3 (Turbopack, App Router, React Server Components)
- **UI Runtime:** React 19 (Server Actions, `useOptimistic`)
- **Styling:** Tailwind CSS v4.3 with native OKLCH `color-mix()`
- **Motion:** Motion (Framer Motion) + CSS `@starting-style`
- **Color Extraction:** `node-vibrant` (WASM) + `colord`
- **CRM & Storage:** PostgreSQL 17 + JSONB palettes + Cloudflare R2
- **Payments:** Razorpay integration (HMAC-SHA256 verified webhooks)
- **Communication:** WhatsApp Meta Cloud API direct routing

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the public website, or [http://localhost:3000/admin](http://localhost:3000/admin) to access the admin cockpit.

### 3. Build for Production
```bash
npm run build
npm start
```
